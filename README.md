# Anlight

Проект на Unreal Engine 5.7 в атмосфере игр серии STALKER.

## Инвентарь

Система инвентаря работает у основного персонажа со здоровьем и выносливостью, а также на отдельной тестовой карте.

- `E` — подобрать предмет;
- `I` — открыть или закрыть рюкзак;
- одинаковые предметы объединяются в стаки;
- предметы можно выбрасывать по одной штуке или все сразу;
- названия, описания, иконки, модели и размеры стаков настраиваются через Blueprint и Data Asset.
